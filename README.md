# 🤖 Taller 3 - Ciencia de Datos, IA y Machine Learning

Repositorio del **Taller 3** que contiene tres proyectos de Machine Learning e Inteligencia Artificial: un sistema de diagnóstico con Random Forest, predicción de precios de vivienda con Regresión Lineal, y detección de rostros con Visión Artificial.
